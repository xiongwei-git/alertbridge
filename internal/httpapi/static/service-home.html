SELF-HOSTED NOTIFICATION GATEWAY

让告警有路可达。

AlertBridge 是一个轻量、自托管的通知网关。统一接收监控、脚本和自动化事件，按路由投递到消息渠道，让人和 Agent 都能了解告警的来龙去脉。

01 / DELIVERY

把投递过程记录下来

持久队列、退避重试和投递记录，配合路由、去重与静默窗口，管理通知从接收到送达的过程。

02 / LIFECYCLE

不止一条通知

区分一次性提醒与故障发生、恢复事件。后台统一管理客户端、通知渠道和路由，查询活跃故障。

03 / AGENTS

让 Agent 只读查询

通过 MCP 查询最近告警、详情和活跃故障。支持 OAuth 授权，读取范围由服务端路由限制，不开放告警修改。
