## 已知限制

- OIDC 登录按钮仍是固定的个人认证服务文案，不能配置名称。文档明确说明；本轮不改 UI 逻辑。
- OIDC 已按 Tinyauth 验证，其他提供方须满足同主机 HTTPS 端点、RS256、PKCE 和 Client Secret Basic 等限制，再单独验证。
- 英文 README 已更新；完整操作文档仍以中文为主。
- 网站只模拟生命周期和查询，不证明真实认证、持久化、重试或送达。
- 单实例、一个 SQLite 连接、一个 Worker 的容量限制保持不变。高可用、聚合、升级、确认、主动唤醒与其他渠道没有发布承诺。

## 文档维护规则

安装示例使用已经发布且与 Compose 配套的版本。发布新功能时同步 README、CHANGELOG、对应操作指南和网站；不要把私人生产操作记录写成通用教程。已正确的协议约束和历史 ADR 不因文案调整而更改。
