01 / INGESTION

HTTP 事件接入

完整事件使用 HMAC，支持幂等和防重放。轻量通知使用请求头 Bearer，路由与级别由服务端固定。

02 / DELIVERY

持久队列与投递记录

事件与投递任务写入 SQLite。单 Worker 执行投递、退避重试和死信处理；HTTP 接收成功不等于渠道送达。

03 / ADMINISTRATION

管理后台与登录

服务端渲染后台管理渠道、客户端、路由和静默。支持本地密码与可选管理员 OIDC，不需要前端运行时。

v0.6.1 / ADMINISTRATOR LOGIN

可选管理员 OIDC

身份提供方验证，本地会话

当前以 Tinyauth 验证。使用 Authorization Code、PKCE S256、state、nonce 和 RS256 ID Token；只允许服务器配置的 issuer + subject 成为管理员。用户名和邮箱不授予权限。

身份提供方 Token 不持久化。登录页等待点击，退出只清除本应用会话；可通过配置保留备用密码入口。

与 MCP OAuth 分开配置

管理员 OIDC 是 AlertBridge 向身份提供方登录；MCP OAuth 是 AlertBridge 向 Dots 签发只读令牌。两者的 Client、回调地址和凭据不能互换。

部署需加载 compose.oidc.yaml，并挂载受限 JSON Secret。日常重建、备份和回滚都需保留 overlay 与配置文件。此静态 Demo 不提供真实登录。

适用范围与限制

单节点运维

适用于个人基础设施和小团队：统一脚本通知、跟踪故障发生与恢复、查询渠道投递结果。运行时为一个 HTTP 进程、一个 SQLite 连接和一个投递 Worker。

未实现能力

监控采集、多实例高可用、值班排班、告警聚合、超时升级、告警确认和自动修复，当前不在项目能力范围内。
